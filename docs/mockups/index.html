Simple Menubar Hider — five settings directions

Each mockup is plain HTML and CSS with no network requests. Every one shows the same 8 running apps (Dropbox hidden) plus Skype hidden and not running (2 hidden total), the Accessibility notice and unavailable warning behind the preview switcher, the four general options, and the Focus-icon note. Light and dark follow the system.

A — Single listOne 460×520 window; list on top, options in a footer.
B — PopoverHangs from the menu bar icon; gear reveals general options.
C — TabsToolbar with Apps and General tabs; checkboxes on Apps.
D — Menu onlyNo window: checkmarks, Show-for submenu, login, pause, quit.
E — SidebarSource list groups Hidden, Visible and Not running.
Files: docs/mockups/m3-a-single-list.html, m3-b-popover.html, m3-c-tabs.html, m3-d-menu-only.html, m3-e-sidebar.html, index.html. Works at 1440 px wide; grid wraps on narrow screens.
